## User Guide: QuizMaster

### 1. Home Page

The home page introduces the system and provides navigation options such as login and signup.

---

### 2. Signup Page

Users can create a new account by entering name, email, and password.

---

### 3. Login Page

Registered users can log in using their credentials.

---

### 4. Dashboard

After login, users can:

* Choose quiz subject
* Select difficulty level
* Start quiz

---

### 5. Quiz Page

* Users answer MCQ questions
* Timer controls the quiz duration

---

### 6. Result Page

* Shows total score
* Displays performance

---

### 7. Profile Page

Users can view and update their personal information.

---

### 8. Leaderboard

Shows top users based on scores.

---

### 9. Settings Page

Users can update password and preferences.

---

### 10. FAQ

Q: Do I need to login to take a quiz?
A: Yes, login is required.

Q: Are results saved?
A: Yes, results are stored in the database.
